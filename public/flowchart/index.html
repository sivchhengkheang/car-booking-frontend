📊 5. Entity State Reference Table

Entity State Description
Booking PENDING_PAYMENT 15-minute temporary reservation hold active. Car blocked from other users.
Booking CONFIRMED KHQR payment completed. Booking is active and ready for pick-up.
Booking ACTIVE Customer has picked up the vehicle and trip is underway.
Booking COMPLETED Car returned, inspected, and security deposit refunded.
Booking EXPIRED 15-minute hold timed out without payment; inventory released.
Booking CANCELLED Cancelled by user or host before trip start.
Payment PENDING Baray transaction initialized, waiting for KHQR scan.
Payment COMPLETED KHQR / card funds settled via Bakong or card network.
Payment FAILED Transaction failed or declined.
Payment REFUNDED Deposit or cancelled trip refunded to customer.
